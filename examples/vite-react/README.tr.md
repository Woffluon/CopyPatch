# Vite React statik örneği

[English](README.md) | [Türkçe](README.tr.md)

Bu tarayıcı odaklı fixture, canonical aynı köken `/__copypatch/api/v2` temel yolunu kullanır ve bilinçli olarak Vite development proxy eklemez.

Salt statik Vite dağıtımları doğrulanmış CopyPatch API'sini barındıramaz. React kullanıcı arayüzü ve Node handler aynı dağıtımda olmalıysa `examples/vite-node` örneğini kullanın.
