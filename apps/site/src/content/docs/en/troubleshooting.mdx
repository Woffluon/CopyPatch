  <h2>3. Common Symptoms & Fixes</h2>

  <h3>The Editing Overlay Never Appears</h3>
  <ul>
    <li>Confirm the URL query parameter is exactly <code>?copypatch=1</code>.</li>
    <li>Ensure <code>CopyPatchProvider</code> wraps the active component tree.</li>
    <li>Check the browser Console for JavaScript errors during lazy-loading.</li>
  </ul>

  <h3>Route Returns 404 Not Found</h3>
  <ul>
    <li>Verify that your host router mounts the handler at the exact path: <code>/__copypatch/api/v2</code>.</li>
    <li>In Next.js App Router, ensure the folder name is percent-encoded: <code>app/%5F%5Fcopypatch/api/v2/[...path]/route.ts</code>.</li>
    <li>In Express, ensure <code>app.use('/__copypatch/api/v2', expressMiddleware(backend))</code> is declared <strong>before</strong> <code>express.json()</code> and SPA fallback handlers.</li>
  </ul>

  <h2>4. Frequently Asked Questions (FAQs)</h2>

  <h3>Can I store rich-text or HTML markup in CopyPatch?</h3>
  <p>
    <strong>No.</strong> CopyPatch intentionally adheres to a strict plain-text invariant. Permitting HTML input creates stored XSS risks and allows non-technical editors to break CSS styling and responsive layouts.
  </p>

  <h3>Can I host CopyPatch on a purely static platform (e.g. GitHub Pages)?</h3>
  <p>
    A static export can render default fallback text, but you cannot edit or save copy on static-only hosting. An active Node.js, serverless, or container backend is required to process authenticated mutations and connect to storage.
  </p>
